1. AEM Architecture
Q1. Explain AEM Architecture.
Answer:
AEM architecture consists of:

Author Instance: Used by content authors to create and manage content.
Publish Instance: Serves content to end users.
Dispatcher: Acts as a caching and load-balancing layer.
Content Repository (JCR/Oak): Stores content and configurations.
OSGi Container: Manages Java services and components.
Sling Framework: Maps requests to resources and scripts.

Flow:
Browser
   ↓
Dispatcher
   ↓
Publish Instance
   ↓
Sling Engine
   ↓
JCR Repository
   ↓
HTL Component Rendering
   ↓
Response to User


Q2. Explain Author, Publish, and Dispatcher.
Answer:
Author

Content creation happens here.
Accessible only to content authors.
Workflows and replication are triggered here.

Publish

Public-facing environment.
Receives activated content from Author.
Handles end-user requests.

Dispatcher

Caching layer.
Improves performance.
Protects publish instances.
Performs load balancing.

Scenario Question:
Why do we use Dispatcher?
Answer:
Without Dispatcher, every request hits Publish, increasing server load. Dispatcher caches static content and serves it directly.

Q3. What happens when a page is activated?
Answer:

Author publishes the page.
Replication Agent gets triggered.
Content is transferred to Publish.
Dispatcher cache is invalidated.
New content becomes available.

Q36. How would you explain AEM request flow in a real interview?
Answer (Short Version):
"When a user accesses a page, the request first reaches Dispatcher. If content is cached, Dispatcher serves it directly. Otherwise, it forwards the request to Publish. Sling resolves the URL to a resource in JCR, identifies the component via sling:resourceType, executes the associated HTL and Sling Models, generates HTML, returns the response to Dispatcher, and finally sends it to the browser. The response is then cached for future requests."
This is the exact level of depth typically expected from a 5-year AEM Developer in Cognizant, Accenture, Deloitte, EY, Adobe, IBM, or Capgemini interviews.
